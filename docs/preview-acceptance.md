# Preview 业务验收

## 本地隔离环境

```bash
npm ci
npx playwright install chromium
npm run verify
npm run preview:local
```

`preview:local` 输出一个随机本机端口及临时密码文件的路径。使用其中的 `ROOT001_PASSWORD` 登录 `root001`。脚本新建本地 D1/R2、随机 JWT/PII 密钥，应用唯一初始迁移；不读取现有 `.dev.vars`，不访问远程资源，采用 Preview 的 512 MiB 附件配额。Ctrl+C 停止后删除临时资源。每次启动都是空环境，仅有一个临时 root 账号。

自动浏览器测试采用同一启动方式，运行结束自动清理。截图在 `output/playwright/`；失败追踪在 `output/playwright/results/`，包含测试环境信息，勿发布为公共附件。

## 手动验收顺序

| 流程 | 操作与预期 |
|---|---|
| 学生预约 | `/` 填写资料、同意协议并预约，上传 TXT 或图片；成功页显示业务编号，自动保存凭证并提供私人链接 |
| 我的预约 | 刷新页面后从顶部进入“我的预约”；查看进度、排队、附件，补传附件；待接单订单可取消 |
| 私人链接 | 在另一浏览器打开私人链接；能读取同一预约，地址栏随即移除凭证；仅输入学号或编号无法查询 |
| 存储受限 | 禁用浏览器存储后预约；成功页明确提示保存失败，并提供可复制的私人链接 |
| 名册导入 | root 进入“账号管理”，导入含 `studentId,expectedName` 的 CSV，选择预期角色及授权校区；无效文件整体拒绝，重复导入不覆盖资格 |
| 自主激活 | 统一地址 `/staff/?activate=1` 输入名单内学号、姓名、所属校区、联系信息及自设密码；提交后不能登录 |
| 人工审核 | 管理员对照本人身份核验后勾选申请、填写核验说明，批量通过；拒绝后可重新申请，撤销白名单资格会拒绝待审申请 |
| 维修人员 | 仅看到授权校区待接单摘要和本人订单；接单前不可读取姓名、学号、联系方式、故障详情及附件；接单后才能读写本人订单 |
| 管理者 | 仅管理授权校区订单；账号管理只能处理低于本人角色、校区授权在本人范围内的非保护账号 |
| 账号调整 | 修改角色、授权校区、停用、恢复和重置密码；旧会话失效，恢复后须重新登录；所属校区独立于权限 |
| 凭证补发 | 管理员在预约详情人工核验并填写说明后重签，将新私人链接交给本人；旧链接的查询、排队和附件访问立即失效 |
| 个人设置 | 工作人员本人改密或撤销全部会话后需重新登录；受保护 root 同样可以验证当前密码后改密 |
| 手机端 | 390px 宽度下完成预约、查看、取消和激活；表单与按钮可操作，页面无横向溢出 |

名册示例（仅用于 Preview）：

```csv
studentId,expectedName,expectedRole,authorizedCampuses
20268801,张三,technician,南湖
20268802,李四,admin,南湖|浑南
```

## 云端 Preview 与 Production 边界

本地测试验证 Pages Functions、D1/R2 业务和浏览器行为。云端 Preview 还须检查实际绑定、独立 Secrets、HTTPS、CPU 预算及公网链路。按 [重建发布流程](operations.md) 获得明确发布授权后部署到独立 Preview，重复上表并记录验收地址、提交、时间和结果。

Production 从空 D1/R2 初始化，只导入真实工作人员白名单，不复制 Preview 数据、附件、会话或密钥。云端发布与资源重建不属于上述本地命令。
