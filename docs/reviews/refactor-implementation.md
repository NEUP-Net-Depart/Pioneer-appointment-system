## 数据实施原则

只新增迁移，不修改既有 D1 账本或已执行 SQL。两个受支持迁移链同步追加。先在隔离本地 SQLite/D1 验证全新安装、已有数据转换、二次执行账本及外键完整性。旧队列/预分派不转成虚构接单事实；已有接收、原分派和审计保留，工单回到待接单。旧返修申请不得静默丢弃或虚构到场。

不操作生产数据库，不部署。每个业务切片完成后按仓库 `[refactor]`/`[fix]` 约定提交。
