# 身份与组织映射

`members.id` 是稳定人员标识。账号唯一关联成员，停用不删除任职、维修、签到或审计历史。账号类型只保留登录与系统管理含义；维修能力属于所有有效且具有校区访问范围的工作人员。

| 数据 | 当前用途 |
| --- | --- |
| members | 姓名、学号、所属校区、学院专业、状态 |
| member_department_memberships | 正式任职和交流关系，左闭右开有效期 |
| staff_campus_grants | 配置的账号校区范围 |
| staff_access_campuses | 配置范围加有效站长、主席等全校管理任职的双校区范围 |
| roles / member_roles / role_grants | 系统设置、账号、权限等剩余可配置能力；不能制造维修资格或业务管理身份 |
| attendance_records | 实际发生时间、录入时间、当时姓名/部门/身份快照 |

同一时刻一个正式主部门。调岗或晋升结束旧任职并创建新任职，保留历史。部长、副部长管理当前授权校区各部门；所有站点的站长、副站长及中心主席、副主席管理全部校区。固定业务权限不在角色编辑器中配置。受保护系统账号与自提权限制继续独立执行。

身份用于展示、责任和原有考勤核算。硬件部、办公室、交流关系与有效管理任职参与既有出勤资格判断，维修权限开放不扩大签到资格，不自动生成出勤或时长。周/月报在原计算代码中直接读取这些任职与新班次事实。

0042 是不可修改的历史人员确认迁移；未执行该迁移的旧库仍须满足其一次性输入约束。0047 追加归档并移除维修/办公/交流/业务负责人工作权限包、独立资格和 effective_member_roles 视图，保留原任职、人员及审计。运行时不再读取旧资格、推导角色包或回退旧模型。

激活配置和批准使用有效人员与校区范围，原子创建账号并复制校区授权，不做维修资格审批。CSV 导入与单人创建共用规则，冲突或预览后的数据变化整批拒绝。系统账号和授权修改另行校验，普通资料管理不能绕过受保护账号限制。详细授权见 [authorization.md](authorization.md)。
