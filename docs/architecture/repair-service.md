# 接收与维修服务

业务依据为 [业务规则](../requirements.md)。线上预约按时段限额，预约当天可跨时段接单；现场登记不占线上名额。未到场预约在次日零点过期，已接收设备及维修中工单可跨日继续。

当前有效硬件部任职（含交流维修）可在授权校区接待、开始、交接和结束本人维修；办公室任职可接待，不可成为主修。兼任取全部有效任职的操作并集，不依赖独立维修资格、排班、签到、工作窗口或同时工单数。接收、补传、资料维护和现场登记检查接待权限，开始、交接和结束本人维修检查维修权限；结束他人工单复用现有管理权限。工单状态仍为待接单、维修中、服务已结束；取消及未到场过期保留。

前端只保留“今日工作”入口。GET /api/field/board 返回本校区今日未接收、所有日期已接收未维修及进行中的工单，前端按 receivedAt 分组；本人维修和本人待补照片复用已有查询。接收不写 assignedTo、startedAt 或 status；只有硬件部本人开始操作才写主修及开始时间。已接收的跨日工单可直接开始，原接收人和照片不会被覆盖。搜索复用预约列表的身份查询和完整联系方式索引，候选不输出联系方式。

首次接收记录正反面照片、经办人、实际时间。上传超时后才显示稍后补传，保存经办人和待传标记；经办人从本人待传列表手动上传原图。部分补齐继续待传。无需跨页面图片缓存和自动上传。交接不重复拍摄；当前主修由实际接到设备的工作人员确认接手。

结束结果为已解决、部分解决、未解决、无需维修，说明不超过 1000 字。当前主修或授权校区内具备现有管理权限的部长及以上人员可通过“结束本次服务”结束维修中工单，保留原主修和维修统计归属；审计记录实际操作人及时间，可与主修区分本人结单和他人代结。结束后主修或授权管理人员可更正结果及说明，不能借更正改写接单、交接或结束时间。每次写入以工单版本和当前账号授权版本比较，工单、审计和请求回执在同一 D1 事务提交。

旧排队、预分派、队首、离队重排以及人员占用表全部移除。0045 将旧记录完整归档至 audit_events，已接收但未实际接单的工单仍为待接单，原预分派不会变成主修。旧未修复结果标为历史未修复（未细分），不推断其是否部分解决。

接口：PATCH /api/appointments/:id/status；POST /api/appointments/:id/receive；POST /api/appointments/:id/photos；POST /api/appointments/:id/transfer（接手人本人，receivedDevice=true）；PATCH /api/appointments/:id/correction（仅结果与说明）。写入均携带 revision 与 requestId。

GET /api/field/appointments/:id 为单工单详情及必要联系方式访问入口，自动记录访问人、时间和工单，不在访问审计中复制明文联系信息。列表不提供联系方式批量输出。学生私人凭证接口仅输出显式许可字段，维修说明及操作历史只供内部查看。

维修关联直接使用 appointments.parent_appointment_id / link_kind / linked_by / linked_at。POST /api/appointments/:id/link 将已预约或维修中的本单关联到同一客户已结束的原单，原因接受 continuation（原故障继续处理）、recurrence（原故障复发）、repair_induced（维修引入新故障）。前两者必须提交 sameDeviceAndFault=true；新故障必须单独提交 sameDeviceAndRepairRelated=true，明确核对同一设备及原维修关联，不能沿用原故障确认。更换关联原因或工单后需重新确认。原单结果不变；新单占用原有预约名额，不重复创建。未预约到场可从原单登记现场新单，须重新签名、接收并记录照片。仅仅在维修后发生但尚未核实关联的新问题，不应直接归为“维修引入新故障”。

0046 将全部旧申请字段逐项归档至审计：已排期记录关联已有工单（historical，不推断故障类型），待处理及已拒绝申请分别标记 archived_unplanned / archived_rejected，不虚构到场或继续维护任务。随后删除 repair_followups 及审批权限。原 /repair-followups 路由、服务与前端模块已删除。

工作人员详情提供授权校区内客户历史及关联服务历史；学生嵌套历史也只返回状态与结果。关联返修计数独立于维修结果。PATCH /api/appointments/:id/information 可更正姓名、设备、故障及联系方式，保持主修、状态不变，联系方式变更审计的前后值加密保存。详情支持手动补拍外观变化和经授权核验身份后补发私人查询链接。
