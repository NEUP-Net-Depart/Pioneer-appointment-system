# 连贯的数据加载（issue #73）

工作人员页面先呈现稳定外壳，身份验证通过后开放对应入口。数据刷新保持已有结果；无数据时先显示真实分区与字段，仅未知值等待响应，不显示错误的空状态。权限拒绝仍立即清除受限数据，不为视觉连续性保留已撤销的数据。

## 更新规则

- `useWorkspaceQuery` 同范围刷新保留结果、分页及已加载页数。更改筛选范围时禁用旧分页入口，结果明确标注为上次范围。服务端错误保留最近确认的数据并显示错误。
- 排班任务列表加载完成前不展示“发布首个任务”。切换任务清除旧任务编辑数据，使用预留高度的加载区域，禁止在新任务名下编辑旧班表。
- 统计指标从首次进入就保留固定位置，未加载用破折号；接待概览与页签数量使用 `AnimatedValue`。值不变不重放，真实文本立即可读。
- `shared/data-motion.js` 由 `WorkspacePage` 与弹窗内容接入，用户端预约列表及详情也复用。只对指定数据区域做约 200ms 的高度过渡，对 `data-motion-item` 的已有节点做位置过渡；不做整页淡入淡出。新增区域保留静态标签与适当尺寸，仅值等待响应。普通输入与按钮不因加载被重新挂载。
- 隐藏页面、改变视口、减少动态效果偏好、聚焦区域以及包含签名画布／摄像头的区域均跳过或取消相应动效。连续更新取消旧动效，从当前视觉位置衔接；结束后恢复自然高度，不保留固定高度。嵌套区域避免重复高度动效，弹窗与页面分别负责自己的范围。
- 用户端预约卡片在其他预约变化时保留节点；相同内容不重建。保留键盘焦点，二维码区域预留尺寸。原有预约余量滚动数字保持使用。

## 验证

`tests/e2e/data-continuity.spec.mjs` 覆盖 320、390、768、1440px 的标题位置、局部高度、列表重排、连续更新、自然高度恢复、输入焦点、减少动态效果、隐藏页面、分页入口、排班初始加载及用户预约卡片复用。配合 `workspace-startup`、`workbench`、`roster-flow`、`student-booking` 回归原有启动、扫码、密集班表与预约流程。

新增列表应使用稳定的业务 key；需要布局过渡时将区域加入共享控制器范围、将行标记为 `data-motion-item`。不要以清空数据、切换整页 key、全页透明或延迟业务结果来模拟加载动效。

## 页面代码与业务数据分别加载

- 页面模块由 `workspaceModule` 按需准备，导航的悬停、键盘聚焦和触摸只准备已授权页面的代码，不挂载页面、不查询业务数据。代码尚未到达时保留当前页面，用独立状态提示正在打开；准备完成后同步读取组件再切换，避免已完成的导入仍触发 Suspense 骨架驻留。`WorkspaceSkeleton` 只保留为意外挂起的防御兜底。身份和工作台接口等待先显示静态工作概况与字段。
- 连续导航只接受最后一次选择；代码准备完成后重新经过未保存导航保护和当前权限检查，避免等待期间的编辑被绕过。模块失败在目标页内报错，其他入口继续可用。`tests/e2e/module-navigation.spec.mjs` 覆盖四种屏宽的慢代码、慢数据、意图预加载无业务请求及旧响应不抢回页面。
- 页面组件可用后，真实标题、说明、分区、表头、时段、字段标签、已知且已获授权的列表摘要立即显示。未知数值通过 `DataValue` 显示破折号，禁止伪造零值、正常状态或暂无数据。`DataFields` 只是字段布局，不绘制空白骨架框。
- 成员表单和放号时间使用同一份真实表单结构，读取前禁用控件和提交；读取后原位补值。工单列表摘要仅供显示，接单、转派等权限和动作仍以详情响应为准。未核实的身份、资格与授权不预先开放。
- 表格和统计各区标题先渲染，仅结果等待接口。加载失败保留静态结构并显示错误，未知值不持续声明加载；同范围刷新保留已确认的结果、输入和焦点。
- `tests/e2e/subpage-loading.spec.mjs` 将接口响应延迟，验证固定内容与真实字段先于数据出现、提交禁用、响应后补值、失败原位重试，并覆盖 320、390、768、1440px。

## 数据入场动效预设

`shared/data-motion.js` 统一定义 `dataMotionPresets`：文字淡入 160ms、数字轻滚动 180ms、状态淡入 150ms、非聚焦表单补值 140ms、新列表项在原位置自上而下展开（180ms）、区域高度与既有行重排 200ms。`DataValue` 保留同一节点，仅值变化时入场；`AnimatedValue` 复用数字预设，状态标签使用状态预设。业务值与可访问文本立即更新，不延迟请求和操作状态。

同值不重播；首次静态内容不统一淡出；快速更新取消旧动画；已有焦点、画布／摄像头、隐藏页面、视口变化和减少动态效果设置仍受保护。新行不叠加内部值的重复入场。列表新增行使用稳定 `data-motion-item`，新值使用 `data-motion-value`；不要对整个业务页面加透明度动画。

容器入场复用 `container` 预设：200ms、透明度 0.8→1，不做位移。页面代码首次挂载在布局阶段启动分区入场，后续新增的数据区和卡片由同一观察器识别；只处理外层新增容器，内部值与嵌套区不叠加。已有页面重访时只衔接内容区，保留原节点、草稿与筛选；标题与整个页面不做淡出。可使用 `data-motion-container` 接入自定义容器；常用卡片与数据区已有统一接入。聚焦输入、摄像头、不可见区域及减少动态效果继续跳过。

## 后台动效覆盖与边界

| 页面／环节 | 采用的动效 | 保持稳定的内容 |
| --- | --- | --- |
| 现场工作台、维修、扫码核验、登记 | 任务区入场、人员／工单重排、数量和状态更新、二维码就绪淡入 | 页面标题、输入焦点、扫码和签名资源生命周期 |
| 账号、成员、资格、角色授权 | 新增卡片批次入场、身份与授权摘要更新、列表筛选后位置衔接 | 稳定业务 key、查询条件、授权撤销后的立即清除 |
| 维修／办公排班、收集、候选人员、可用时间 | 任务分区入场、进度条、候选及班次重排、局部高度变化 | 页面标题、正在编辑的字段、原始填报和草稿 |
| 个人资料、账号安全、签到、考勤、请假换班及审批 | 已读取字段补值、记录和反馈入场、详情分区展开 | 表单结构、操作顺序与焦点 |
| 预约记录、附件、维修详情、数据维护 | 结果行入场／重排、状态与数量更新、详情内容衔接 | 分页、筛选、权限、删除结果立即生效 |
| 容量、地点、暂停与公告配置、统计 | 已读取字段补值、结果摘要更新、统计分布条插值 | 控件及固定标签、原生 meter/progress 的即时可访问值 |
| 侧栏、普通详情与共享弹窗 | 侧栏组折叠、普通 details 展开、弹窗局部淡入／关闭 | 标题定位、键盘焦点约束、关闭后焦点恢复 |

短提示逐字淡入只用于维修工作台的短任务提示：最多 20 个字符，共用一次 220ms 动画。屏幕阅读器立即读取完整文本。长说明、姓名、按钮、表格内容和错误信息使用整体轻淡入，不做逐字播放。

普通弹窗打开 180ms、用户主动关闭 120ms，只改变透明度，不移动标题。提交成功、父级关闭、权限清除立即更新；包含摄像头或画布的弹窗立即关闭，资源释放不等待动画。普通原生折叠区由 CSS 单独负责，不再叠加 JS 高度动画；浮层式“更多操作”不使用折叠裁剪。页面根节点以及包含页面标题的容器不做整块入场或位移动画，内部区块仍可独立衔接。

### 性能约束

- 每个活动观察范围单批最多 24 个动画，列表错峰 12ms、累计最多 60ms；超过预算的项目直接显示。无循环装饰动效，不引入额外动画依赖。
- DOM 更新合并到动画帧；先完成尺寸与样式读取，再统一启动动画。屏外行的内部字段不重复测量；原生折叠进行时不逐帧重新测量整个列表。
- 新容器与内部文字不叠加入场。已有数字组件复用原预设，避免两个控制器同时驱动同一节点。相同值不重放；连续更新取消旧动画。
- 滚动、视口变化、页面隐藏及减少动态效果设置会重置或跳过动效。聚焦区域、摄像头与画布不做布局位移。
- 删除的业务行不保留副本等待退场；只允许剩余行和局部区域衔接。权限变化先清除数据，不延迟到动效结束。

### 本轮验证依据

`admin-motion.spec.mjs` 覆盖账号卡在 320、390、768、1440px 的节点复用与焦点、500 行列表的动画数量和错峰上限、连续更新、减少动态效果、弹窗焦点恢复、侧栏 inert、短提示可访问性、原生折叠／浮层可操作性、统计条以及标题容器不位移。性能数据由测试输出至 `output/issue-73/motion-performance.json`；这是本机 Chromium 的测量，不能代替低端手机性能结论。

配合 `data-continuity`、`module-navigation`、`subpage-loading`、`workspace-startup`、成员和授权测试检查代码加载、慢数据、局部错误与重试。隔离数据库中的 `field-flow`、`roster-flow`、`workbench` 验证接单、转派、完成维修、摄像头释放、后台暂停、每班七人、考勤、请假和换班；所有岗位页面另检查标题及导航在四种宽度的位置。上表记录代码接入范围，不代表对每个页面的所有业务组合逐一人工验收。


## 列表动效收敛

账号列表、授权角色列表与预约记录使用同一套 `data-motion-list="reveal"` 行展开：列表顺序决定短错峰顺序，每行在原位置自上而下揭示，不从其他位置飞入，不对文字再叠加动画。角色按钮也显式接入共享列表，避免只有文字变化而整列没有展开。

权限功能分类同样按替换结果处理，不把“全部功能→接待与维修”的筛选当作已有行的位置重排。普通内容容器只轻淡入，不参与位置插值；其他确有排序含义的列表只保留同列垂直衔接，跨列和横向布局变化不播放飞入。标题、筛选条及角色编辑区保持原位置。新增移动／桌面浏览器断言检查三类列表的展开方向、顺序和分类切换无位移。


## 连贯性与交互补齐

- 从其他一级页面返回已挂载页面时，同样衔接内容区；不重新挂载列表或重置筛选，不以动效启动业务查询。页内已访问分区恢复显示由原有观察器识别。
- 页签、导航、按钮、输入框焦点及身份／状态底色使用共享短过渡；不使用 `transition: all`，不改变触控目标位置。减少动态效果时关闭这些过渡。普通弹窗遮罩与内容使用一致的短淡入。
- 非相关响应不再取消已开始的列表展开或文字淡入。只有需要重新测量的布局动效衔接当前位置；同一节点的新值可替换旧值动画，入场父容器未结束时不叠加内部淡入。正在播放和新增加的动效共用原有 24 个预算。
- 嵌套内容增长由实际改变高度的最外层内容区负责，静态包装层和包含主标题的外层不再吞掉子区展开。结束后回归自然尺寸。

新增浏览器回归检查：第二个响应不打断首批展开、父容器入场中更新身份立即可读且不叠加动画、静态标题包装中的内容展开、重访页面保留筛选与原节点、交互过渡及减少动态效果。
