## 业务主线

- 成员是稳定的人，账号是登录身份；部门任职、工作属性、角色授权、当日岗位分别维护。历史记录按 memberId 连续关联，组织归属按发生时点解释。
- 普通成员完成个人资料、时间填报、签到与申请；维修 / 交流人员先恢复当前工单，再按到岗和占用状态接单；办公人员负责当日接待与连续登记。
- 负责人资格不等于当日任命。长期排班 / 审批授权与当日现场权限分别计算；最高管理员参与维修时也遵循同一维修流程。
- 客户预约、工作人员签到、现场登记和实际维修分别形成事实；维修码、私人访问凭证和考勤凭证不得混用。
- 每个动作使用完整授权项的范围、条件和有效期；列表、详情、搜索、附件、统计、导出必须一致。页面 actions 仅作提示，写入重新校验。
- 关键命令将事实、版本断言、审计与回执一并提交；重试保持同一 requestId，返回结果前仍按当前授权投影。
