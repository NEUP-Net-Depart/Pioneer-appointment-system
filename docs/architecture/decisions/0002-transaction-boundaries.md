# 决策：跨模块命令使用 D1 批处理

日期：2026-10-14

接单、签到、换班、请假审批和权限变更都需要同时保存业务事实、版本断言、审计和请求回执。应用服务生成参数化命令，D1 `batch()` 在一次事务内执行；查询失败或版本冲突不应产生半条业务事实。R2 上传继续使用元数据状态和补偿清理。

请假提交将申请、必需审计和请求回执同批保存；同键不同内容拒绝，失败后不留待处理回执。审批及撤回按 pending、revision、当前授权版本提交，审计失败整体回滚；重放返回已保存的决定。未变更班次用 `origin_assignment_id` 延续请假，`roster_leave_facts` 解析历史中间版本引用，不改写原申请和实际签到。批准请假扣减预计覆盖，实际到岗仍由签到事实决定。对应回归位于 `leave-review.test.mjs`、`field-workflow.test.mjs`、`staff-upgrade.test.mjs` 与浏览器 `roster-flow.spec.mjs`。
