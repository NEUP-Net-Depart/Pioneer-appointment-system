# 学生预约访问与凭证恢复

学生免注册。预约成功时服务端用安全随机数生成 32 字节（256 位）凭证，返回一次，D1 仅保存 SHA-256。业务编号继续可预测，仅用于展示、排队排序和工作人员沟通，不能授予访问权。

学生浏览器在 localStorage 中保存预约编号与凭证，不保存联系方式或其他预约资料。“我的预约”逐条凭证读取服务端最新状态。清除浏览器数据、隐私模式或禁用存储可能失去本机凭证；成功页同时提供私人链接。私人链接以 URL fragment 保存凭证，打开后立即从地址栏移除；网络请求使用 X-Appointment-Token 请求头，禁止凭证明文出现在 API query。

查询、取消、个人排队、附件上传/列表/下载共用凭证验证。学生只可取消 pending/awaiting_claim；即使携带有效凭证也不能派单或提交维修记录。公开接口只返回名额总量。工作人员请求使用 JWT，并在阶段 3 统一角色、校区及订单归属检查。

持有私人链接的人能访问该预约，用户界面提示勿转发。浏览器不自动找回、同步或按照学号扫描预约。服务不使用短信、邮箱或额外学生密码。

遗失恢复：学生联系工作人员，管理员对照本人学生证、预约资料等人工核验；在 POST /api/appointments/:id/credential 中显式提交 identityVerified=true 和至少 8 字的核验说明。服务在同一 D1 batch 中更新凭证哈希及审核记录，通过 revision 防止并发重签。旧凭证立即失效，包括排队与附件入口；新凭证仅返回一次，管理员将新的私人链接交给核验通过的学生。
