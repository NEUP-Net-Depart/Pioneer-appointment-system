# 管理后台交互约定

## 选择控件

后台使用 `SelectionControls.jsx` 的 `Select`、`DatePicker` 和 `DateTimePicker`，时分使用 `TimePicker`，工作周使用 `WeekPicker`。不再新增原生选择菜单、日期或时间弹窗，也不再为同一类字段单独实现一套选项弹层。

- `Select` 保留 `option` 的值、标签、禁用和必填语义，`onChange` 提供 `event.target.value`；有 `name` 的字段仍参与 `FormData`。超过七项自动提供本地搜索，已加载的选项不因搜索重复请求。
- `DatePicker` 按天、工作周或月份选择，保留手工输入、必填、最早和最晚日期校验。日历从周日排到周六，工作周归一到周日，例如 2026-11-15 至 2026-11-21。`WeekPicker` 将显示日期映射至原有周一排班标识（该周为 11-16），保留已有班表、版本和空闲填报的存储键。默认工作周用 `rosterWeekKey`，周日即进入新一周；原 `weekRange` 仅保留在兼容旧接口及统计数据键的内部逻辑。`DateTimePicker` 才组合日期与时分；只需要时分的业务直接用 `TimePicker`。
- `TimePicker` 点击输入框即展开且保留输入焦点；输入与辉光管双向实时联动，支持 `HH:mm` 或连续四位数字。触摸拖动和方向键分别调整小时十位、小时个位、分钟十位、分钟个位。鼠标滚轮按悬停位调整所属小时或分钟：十位每次加减 10，个位每次加减 1 并自动进位，分别在 00–23、00–59 循环，不跨组进位；单个滚轮事件最多走一个步长，避免设备滚动量较大时跳过多个值。各位拖动在合法范围循环，分钟覆盖 00–59，不设离散时间档位。小时十位切到 2 时将超范围个位收至 3，避免产生 24–29 点。取消恢复打开前的值，确认收起，业务保存仍由所属表单执行。四个触控区域至少 44px 宽，弹层跟随手机可视视口避让键盘。读数是五支并排的辉光管，中间一支只点亮小数点；每支管内叠放十根金属丝阴极，切换数字时旧阴极熄灭、新阴极原位点亮，不做滚动。减少动效偏好下直接切换。
- 考勤补录沿用选定值班日的默认起始时刻，不再重复选择日期或时间；已有签到记录的修正仅选择当天时分，继续提交原有记录版本与原因。
- 管理成员新增任职复用新增人员的部门和独立身份控件。部门默认“不添加部门”，可单选部门、只勾选独立身份或组合添加，至少选择一项。组合项共用生效和结束日期，通过一次事务保存，任何一项校验或写入失败都不留下部分任职；接替选项只作用于正式部门。
- 弹层挂载到所属 `dialog`，普通页面挂载到 `body`，避免被原生模态层遮挡或变成不可交互内容。定位按可用空间向上或向下展开，并限制在视口内。切页或所属控件隐藏时自动收起，包含不触发鼠标事件的键盘导航。
- 标签始终表达业务字段。视觉上不重复解释用户已能辨认的小时、分钟等信息；屏幕阅读器仍有对应名称。支持方向键、Escape、关闭后返回焦点。

## 校区属于任务

不使用页面总校区开关。今日考勤、安排下周、报表、接待工作台、个人签到及预约配置的各个任务分别保留校区范围，选项来自当前授权。

使用 `CampusScope` 呈现短校区选项。单校区显示校区名称；导出、补录等相关弹窗继承发起任务的范围，不再自行默认到另一个校区。报表的按周导出显示继承范围，不能在弹窗里悄悄切换为全部。

成员所属校区、账号授权校区和复制配置的目标校区属于资料或写入参数，保留各自明确的字段，不与查看范围合并。空闲填报和本人跨校区班次继续保留完整信息。本人签到历史放在“我的值班”，管理报表不混入不受报表范围控制的个人历史。

## 刷新与草稿

使用 `RefreshButton`，标签直接指出对象，例如“刷新人员”“刷新当日容量”“读取最新班表”。回调必须返回实际请求的 Promise；请求失败必须抛错或返回查询错误，不能提前显示成功。

进行中禁止重复触发，完成后显示更新时间，失败保留已有内容并给出失败状态。反馈区域预留空间，不卸载已经显示的数据，不重置筛选和滚动。刷新只覆盖当前任务需要的查询，不通过新增全后台轮询处理同步。

刷新控件以当前任务的日期、校区或筛选范围作为 React `key`。切换范围时重置刷新反馈，旧请求完成后不能在新范围显示“已更新”。

有草稿时沿用原有版本、合并和冲突规则。排班重新读取保留手动新增并合并远端结果；禁止通过刷新无提示地覆盖输入。个人资料读取到新数据时更新未编辑的表单，正在编辑的内容继续以原版本保存或提示冲突。

## 布局与验证

成员详情将“基本资料”和“任职与身份”分为独立页签。任职页先展示记录，点击“新增任职”后展示独立表单，保存或取消后收起；结束操作仍在对应记录上发起。独立身份复用紧凑的带边框 fieldset，局部样式不能被详情页的通用 fieldset 重置覆盖。

页面标题使用 `WorkspaceHeader`，章节标题与动作使用 `WorkspaceToolbar`；带标签的筛选字段与章节标题分开排布。动作组允许换行，控件点击高度通常为 44px，组内间距使用 8/12/16px。刷新反馈的高度在父容器中预留。

页面只保留三个视觉层级：页面标题和导航、任务范围和操作、数据内容。页面外层负责边距；嵌入子页面不再追加一层页面边距。任务工具栏用分隔线，不重复套白色卡片。数据卡片内的校区、分类等使用留白和分隔线。筛选字段与操作按钮分组，不能依靠 `order` 在小屏临时混排。

同一操作行的校区切换外框、日期输入、下拉框和按钮统一为 44px，包含边框与内边距；数字或图标在自己的控件内居中。输入标签单独成行，操作与输入框底边对齐。人员工具栏按父容器宽度布局：先操作区，再筛选区；窄屏搜索独占一行，两个短筛选均分下一行。禁止子元素保留比父网格更大的最小宽度。

短操作组要按按钮的实际最小宽度计算布局，不能让 flex 的固有宽度使宽屏按钮意外换行。工作台三个短操作使用网格，宽屏按内容分列，窄屏等分。嵌入式签到历史跟随父容器宽度，不叠加独立页面宽度上限。公告刷新与新增归属公告标题区；标题间距、卡片间距和刷新反馈空间分别只预留一次，避免多层容器重复叠加留白。

手机布局集中在 `workspace-mobile.css`，按任务容器声明行列，不依赖桌面 flex 自动换行。业务请求、权限和表单状态仍共用同一实现。今日值班的校区、日期与操作分行；手机刷新可用 `compactOnMobile` 保留 44px 图标入口、完整可访问名称和更新反馈。今日工作签到入口使用图标、标题/校区、操作三列，只收起重复说明。报表月份及范围独占一行；人员、账号及预约筛选有明确网格。空闲填报在手机上按校区分组，七天全部可见；窄弹窗的周选择器使用两行，不能裁掉日期。人员选择列表的复选框规则必须限定 `input[type='checkbox']`，不能影响同容器中的搜索框。

移动端验证包括 320、375、430、600px，覆盖默认页、展开表单、选人弹窗及刷新反馈；检查实际文字是否被裁切、日期能否完整显示、按钮点击区域和同组操作位置，不仅检查页面有没有横向滚动条。

下拉选项弹层跟随触发框宽度，日历保留固定七列可用尺寸并避让视口；更多操作向内侧对齐。勾选框图形固定 18px 正方形，仅绘制一个勾号，44px 点击范围由外部标签提供。辅助说明使用 `HelpHint`，支持悬停、键盘聚焦与触屏点击，浮层不改变页面布局；错误、冲突和实际业务状态继续直接显示。

基础表单样式使用低优先级选择器，工作区的全局控件缩放规则不覆盖独立弹层。弹层组件自行负责格子尺寸、按钮材质与输入字号，避免在不同宿主内变成另一套样式。

保留数字原有排版与数据动效，不用占位组件替换已经下载完成的界面。列表延伸向下，固定区域不因数据到达重新排版。

路由首次显示与返回时不重播整块容器动效。子页通过 `hidden` 切换可见性时，动效观察器重设几何及数值基准；之后新增的数据行和数值变化仍使用原有局部动效。手机普通弹窗按内容高度从底部展示，最高占视口 85%，超出部分在面板内滚动；人员编辑等侧面板仍使用完整页面空间，确认对话框保留居中样式。

`tests/e2e/admin-controls.spec.mjs` 覆盖弹窗内搜索、焦点返回、任务校区隔离、单校区授权、导出继承和桌面/手机工具栏。业务回归继续由现有人员、预约、排班、考勤、保修和缓存流程用例验证。新增控件应验证长选项、空结果、慢请求、失败、屏幕边缘和窄屏，避免只检查静态默认状态。

本地浏览器测试分配预览端口时，先验证该端口可以通过 HTTP Fetch 访问，再交给 Wrangler。仅验证 TCP 可监听会漏掉 10080 等浏览器禁止访问的端口，导致服务已启动但健康检查持续失败。
