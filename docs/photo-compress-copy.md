## 2. 处理阶段和大小反馈：新增

来源：[图片压缩](../shared/image-compress.js)、[共用照片选择组件](../shared/photo-input.js)。

| 场景 | 文案 |
|---|---|
| 开始读取文件 | 正在读取照片 |
| 解码和方向处理 | 正在解码并校正方向 |
| 压缩尝试 | 正在压缩照片（第 {次数} 次） |
| 优化到期望大小 | 正在优化照片大小 |
| 准备完成 | 照片已准备好 |
| 压缩失败但允许使用原图 | 将使用原图 |
| 上传中 | 正在上传 |
| 后台弹窗上传完成 | 已上传 |
| 上传失败 | 上传失败，请重试 |
| 扫码上传完成或恢复已上传照片 | 照片已上传，可直接重试签到 |

“照片已上传，可直接重试签到”沿用扫码工作台已有文字。照片仍在本页时，新增尺寸对比；刷新恢复附件 ID 时继续显示已有恢复提示。

实际显示格式：

| 状态 | 格式 | 示例 |
|---|---|---|
| 处理中 | `{原始大小} · {处理阶段}` | `8.4 MB · 正在压缩照片（第 2 次）` |
| 已完成压缩 | `{原始大小} → {最终大小} · 照片已准备好` | `8.4 MB → 1.3 MB · 照片已准备好` |
| 上传中 | `{原始大小} → {最终大小} · 正在上传` | `8.4 MB → 1.3 MB · 正在上传` |
| 原图回退 | `{原始大小} → {最终大小} · {回退原因} · {当前状态}` | `1.2 MB → 1.2 MB · 照片压缩失败（JPEG 编码失败），原图不超过 2 MB，将上传原图 · 照片已准备好` |

小于 1 MB 使用整数 KB，最小显示为 1 KB；1 MB 及以上保留一位小数。进度条表示照片处理阶段，上传状态以文字显示。

## 4. HEIC/HEIF 与压缩失败：新增

来源：[图片压缩](../shared/image-compress.js)。

| 场景 | 当前文案 |
|---|---|
| HEIC/HEIF 文件内容无法识别 | 无法读取 HEIC/HEIF 照片，请转为 JPG，或在相机设置中选择“兼容性最佳”后重新拍摄 |
| 浏览器无法解码或转换 HEIC/HEIF | 当前浏览器无法处理 HEIC/HEIF 照片，请转为 JPG，或在相机设置中选择“兼容性最佳”后重新拍摄 |
| 压缩失败，受支持原图不超过 2 MB | 照片压缩失败（{失败原因}），原图不超过 2 MB，将上传原图 |
| 压缩失败，原图超过 2 MB | 照片压缩失败（{失败原因}），原图超过 2 MB，请重新选择或拍摄照片 |

HEIC/HEIF 转换成功后上传 JPEG；转换失败不回退上传 HEIC/HEIF 原文件。原图回退提示会显示在照片下方，并通过提示条告知用户。

`{失败原因}` 可能包含以下组件、解码或编码错误；这些通常出现在上面的完整失败提示中：

- 图片处理组件加载失败
- 图片解码失败，照片可能损坏或浏览器不支持此格式
- 浏览器不支持图片读取
- 浏览器不支持图片画布
- JPEG 编码失败
- 浏览器不支持 JPEG 编码
- 照片压缩后仍超过 2 MB

## 5. 服务端校验：新增或修改

来源：[附件输入校验](../src/lib/attachment-input.js)。

| 场景 | 当前文案 | 变化 |
|---|---|---|
| 签到照片超过 2 MB | 签到照片大小不能超过 2 MB | 新增签到专用大小提示；正、反面分别校验 |
| MIME 或文件名不受支持 | 附件格式不支持 | 原先“附件格式不支持或大小超过 5 MB”拆分为格式提示和大小提示 |
| Base64 编码非法或内容为空 | 附件格式不正确 | 与大小超限分开，避免用 5 MB 提示描述格式错误 |

与上述流程相关、继续保留的服务端提示：

- 附件大小不能超过 5 MB
- 附件内容与文件类型不匹配
- 附件用途不正确
- 签到照片必须为图片

一般附件仍为每个文件最多 5 MB，不修改一般附件页面的 5 MB 说明。

## 6. 业务文档：新增或修改

来源：[业务规则](requirements.md)。

签到照片规则调整为：

> 本次签到人必须上传电脑正、反两面图片，全部保存后才进入维修中；每张最多 2 MB，保留 180 天。

新增压缩策略说明：

> 签到照片通过系统原生相机或相册选择，使用 `blueimp-load-image` 统一解码、校正 EXIF 方向和缩放，最长边为 2560 px。JPEG 初始质量为 0.85，期望大小 1–1.5 MB；较小照片不会为达到目标而放大。超过 2 MB 时逐步降低质量，必要时降低分辨率。界面显示处理进度、压缩前后大小和最终预览；更换照片后清除旧附件 ID。压缩失败会明确提示，仅支持 JPG、PNG、WebP 且不超过 2 MB 的原图可以回退上传。HEIC/HEIF 仅在浏览器可解码并转换为 JPEG 时接受，否则提示转换格式或重新拍摄。

新增双入口和恢复机制说明：

> 后台签到弹窗与扫码工作台共用照片处理组件，处理进度、压缩前后大小、错误提示和最终预览保持一致。扫码入口保留按账号和工单保存附件 ID 的恢复机制；更换照片后清除该面的旧 ID，重试时复用未更换照片的已上传附件。
