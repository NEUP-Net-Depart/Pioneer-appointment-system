# 工作人员平台：复杂内容的呈现规则

沿用 `workspace-foundation.css` 的页面外壳、字号、颜色和间距；业务模块只决定内容结构。以下规则同时用于接待、排班、成员、授权、审批与统计，不能仅按少量示例设计。

## 操作层级

- 页面标题回答所在位置；范围和筛选在标题下方对齐。任务区突出下一步主要操作。
- 重复记录只显示识别信息、业务状态和一个详情／调整入口；移动、替换、移除、锁定等集中到记录详情。不能为每条记录常驻一组按钮。
- 重新生成、重新开放等低频操作使用 `WorkspaceMoreActions`。当前主要操作、保存、错误恢复不折叠。
- 手机“工作入口”使用 `WorkspaceLauncher`，按业务分组和两列功能项呈现，较宽窗口并排展示分组；当前页面有明确选中态。搜索只在现有授权入口内进行。
- 对话框操作顺序统一为返回／取消、主要确认；破坏性操作保留文字说明，使用风险色，不与主操作并列争夺强调。

## 重复内容与信息密度

- 人员行统一姓名、身份、状态的层级；状态列和操作列对齐。身份允许换行，姓名不得裁切到无法辨认。
- 接待人员区支持姓名、部门和身份搜索；排班候选支持姓名搜索。空结果说明如何恢复，不丢失筛选。
- 多个授权按角色显示范围及有效期摘要，展开后编辑；可用时间按时段列示，避免一整段长字符串。
- 桌面有足够空间时显示整周；中等宽度减少并排列数，手机切换日期。桌面快捷拖动之外始终保留按钮操作。
- 用每校区每日 1 名负责人＋6 名普通人员、两个校区共 56 人的展示夹具检查密度，业务操作另用真实隔离 D1 流程回归。

## 响应式与可访问性

- 筛选字段允许换行并共享基线，按钮不得挤成单字竖排。窄屏页签按可读列数排布，四项采用两列。
- 交互目标至少 44px；详情内保留键盘焦点，关闭后返回入口；更多操作支持 Escape、外部点击和焦点移出关闭。
- 弹窗打开时锁住背景滚动，内容区独立滚动；多个弹窗叠加时，最后一个关闭后才恢复背景滚动。
- 列表刷新保留现有内容、输入和焦点。编辑面板打开时暂停对应班表刷新。
- 320、390、768、1440px 检查页面溢出、长姓名、多身份、重复控件和滚动。检查截图并操作真实流程，不能只凭组件渲染通过判定可用。

实现入口：`WorkspaceSections.tsx`、`WorkspaceMoreActions.tsx`、`RosterAssignment.jsx`、`workspace-foundation.css`。新页面优先复用这些模式，不再引入独立的按钮和基础容器规则。
