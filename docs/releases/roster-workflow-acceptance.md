# 排班收集与发布验收

本轮维修与办公共用“发布收集 → 整周填报 → 结束收集 → 自动排班 → 人工调整 → 检查发布 → 修订”流程。每日人数在收集任务内按日期、校区设置；维修为普通人员下限，另含恰好一名负责人；办公为目标人数，默认一人，优先均衡周内班次数，每人每天最多一班。

## 本地操作路径

运行 `npm run preview:field` 创建隔离 D1/R2，控制台显示当前地址。`root001` 和夹具账号 `20261001`～`20261004` 的本地密码为 `StaffTest!2026`。额外验收数据只写入本地临时库，不随部署发布。

1. 负责人进入值班管理的维修或办公排班管理，新建收集任务，选择校区、部门与成员，统一填写人数后逐日调整；如需长期收集，开启“结束后继续收集下一周”，设置后续每周截止时间。
2. 成员进入“我的 → 班次与排班”勾选日期与校区，提交完整两小时的班次，或明确选择整周无法参加。开启自动延续后，后续同岗位任务按星期和校区带入新任务的完整班次，标明自动来源；手动提交不被覆盖。自动延续可单独关闭。旧版部分时段填报不会被静默扩展为整次可用。
3. 负责人查看已提交／应提交、未填报名单和每日候选缺口。提前结束时核对未提交名单，结束后生成自动排班。
4. 从具体日期添加、移动、替换或移除人员，候选优先显示未安排人员，办公按已安排次数排序。移动只修改选中的原班次；额外安排不删除其他安排。超出原填报时间需明确确认，原填报保留；资格、授权及实际时间重叠不能绕过。锁定仅作用于具体班次。
5. 每项检查问题均可点击“处理此问题”。缺额、负责人数量、周内次数等业务偏差允许逐项确认并填写原因后发布，确认绑定当前草稿版本及人员事实；资格、越权、实际时间重叠与受保护班次禁止强制发布。发布留下原子审计和确认记录。成员端应出现相同班次。
6. 点击“调整已发布班表”复制当前安排。发布修订前旧班表保持有效；已签到、过去日期和暂停日期的原班次保留。重新开放收集不会自动修改任何班表。办公负责人可在授权校区、部门及有效期内管理维修排班，此权限不会自动赋予维修资格或现场转派能力。

## 一次发布、按周填报

循环收集只发布一次，工作人员一直从同一个普通任务入口填写当前对应周。本次到期或提前结束后，下一工作周立即开放；历史周可同时重新开放补填，不回退当前周或再次推进周次。截止时间按北京时间、值班前一周解释；不使用定时作业、后台补发或按周重复发布任务。管理端在同一任务中切换工作周，分别管理收集、草稿及已发布班表。

数据库中的周次记录仅用于保存各周事实，打开任务时按日历解析当前周；长期无人访问不会补建所有错过的周。未来设置变更不改写已经建立的周次、原填报和已发布班表。负责人停用或授权失效时，只提示该任务需要由有管理权限的负责人接管，不阻断其他收集任务。

自动延续以截止时有效的偏好为准。即使截止后才首次查看，也可恢复当时已启用的选择；截止后才开启的偏好不能回填过去。已有提交始终优先，普通手动迟交仍被拒绝。关闭个人自动延续不删除已有提交。

正式版的编号候选搜索已接入新维修工作台：两位及以上尾号仅查当天，含前段和短横线的编号可跨日期查找。搜索与详情复用同一对象权限判断，仅返回编号、校区、日期、时段和状态。

## 签到、暂停与周核算

签到按钮位于工作台和个人中心，展示工作人员签到码的面板仅负责展示码。授权校区内的有效负责人无需排班即可自行签到，当天排班的办公人员也可直接提交，其他成员打开统一扫描器后启动摄像头；识别、关闭、切页、隐藏或离开页面均释放占用，返回页面不自动重启。成功面板保留首次签到时间和身份；刷新权限事实不会重建整个工作区或丢失结果。

“预约配置 → 暂停日期”按校区选择指定日期，确认后停止新预约、现场登记、开始维修和所有值班签到（含补录）；自动排班与填报跳过暂停日。已有客户预约、已发布班次与考勤保留并标记，修订和重新生成不得删除受保护班次。恢复时继续使用原容量。受影响预约预览不带客户隐私，联系方式通过原有权限控制的记录页面查看。

“考勤核查 → 按周核算导出”每人每周一行，跨授权校区合并，实际有效签到与核算次数分开显示。可独立开启“仅计首次有效签到”和“负责人每周计一次”，默认都关闭；有效负责人可无签到记录，兼任身份不重复计数，授权校区整周暂停时计零。暂停日考勤被排除，原始记录不变。授权范围先过滤，再汇总；预览与导出使用同一筛选和算法。历史授权区间按现有任职记录计算，原系统未保留的旧授权编辑内容不作推测。

## 本轮本地验证（2026-10-19）

254 项后端测试、180 项通用浏览器测试与 41 项工作人员浏览器测试通过；两条数据库迁移链的首次应用、重复应用和外键检查通过。静态检查、类型检查、架构与平台审计通过。人工复核四种宽度下的密集班表、逐项发布确认、签到结果、暂停确认和周核算截图。普通成员的管理入口隐藏、直接访问拒绝、撤权退出、摄像头释放与后台暂停均纳入回归。

浏览器用例使用临时数据库，独立建立自行签到测试账号，不依赖其他用例尚未签到的状态；周核算按实际响应核对人数与去重，不假定库内只有一名负责人。本地人工验收库保留原有账号、预约与操作记录；未运行排班或签到来替代人工验收。本轮仅作本地分类提交，未操作云端数据库、推送或合并。
