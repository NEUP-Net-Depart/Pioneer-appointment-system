# 业务规则与权限

表单选项与长度限制以 [学生配置](../shared/student-booking.js) 和 [服务端校验](../src/lib/validation.js) 为准，接口定义见 [路由](../src/routes/)。

QQ 账号须为 5～12 位数字且首位非 0。所有有长度上限的输入均保留完整内容，仅在超长时提示「必须在 xx 字以内」并阻止继续或提交，修改至上限以内后清除长度提示。

## 学生预约

| 项目 | 规则 |
|---|---|
| 访问 | 免注册；私人凭证用于查询、取消和附件访问 |
| 时间 | 上海时区，今天至第 3 天内的周一至周四，19:00–21:00 分四个半小时时段；时段结束后不能新约，预约默认当日 21:30 到期 |
| 名额 | 按校区、周几和时段配置，默认每段 5 人；日期首次预约后冻结容量，仅取消释放名额。同学号同服务日最多一条有效线上预约，已完成计入，取消、逾期及现场登记不计入 |
| 地点 | 南湖默认「大学生活动中心202室」，浑南默认「大学生活动中心308室」；管理员可按日期替换完整地址，已有配置优先，显式留空不可约；预约保存地点快照，变更需人工通知 |
| 设备 | 品牌必填并支持手填，型号选填；仅笔记本询问液金，笔记本＋Dell 显示选填 G15 问题；在保必答，均支持「是／否／不清楚」 |
| 故障与联系 | 故障单选，「其他」须补充说明；姓名、学号、学院和 QQ／微信二选一账号必填，邮箱选填；学院不按校区过滤，隐藏字段不提交 |
| 协议 | 提交前同意协议并独立手写签名；阅读不自动同意，取消重签保留原签名；免费维修，配件自备，普通硅脂由中心提供 |
| 照片 | 故障照片选填，最多 4 张 JPG／PNG／WebP，单张 ≤2 MiB、最长边 2560 px；本机压缩，预约成功后逐张上传，失败可重试或补传，保留 180 天 |

填写分为到场时间、设备与联系、核对与签名三步，校区和时段不预选。时间或地点失效时返回选择页并保留其他输入。草稿在当前会话保存约两小时，恢复须确认并重新选择照片、同意协议和签名。

创建请求携带 `Idempotency-Key`（32 字节随机值的 43 字符 base64url 编码）；同键重试返回原预约，同键不同内容拒绝。结果不明时通过 `/api/booking-attempts/resolve` 核实并保留原键。成功后展示时间、完整地点和维修二维码。

## 状态与维修

| 状态 | 数据库值 | 操作 |
|---|---|---|
| 已预约 | `booked` | 学生可取消；工作人员拍照签到后开始维修 |
| 维修中 | `in_progress` | 仅负责人完成维修，不自动逾期 |
| 已完成 | `completed` | 必须记录说明和结果：修复成功、未修复或无需维修 |
| 已取消 | `cancelled` | 维修结果为空 |
| 已逾期 | `expired` | 有效期结束且未记录维修开始，维修结果为空 |

工作人员可扫码、选图或输入编号查找工单。签到须上传两张不同的设备正反面照片，每张 ≤2 MiB，保留 180 天；每人同时最多一张维修中工单。现场登记不占线上容量，每人最多一条待签到记录，当日 21:30 后不可新建。

管理员通过 `action=correct` 纠错。截止后恢复预约需填写原因并指定未来截止时间，重新校验容量、清空维修记录并重新拍照签到。历史缺失结果的 `legacy_unknown` 不计入修复成功率。

## 账号与凭证

| 角色 | 权限 |
|---|---|
| `technician` | 授权校区待接单设备摘要及本人工单，签到后读取详情与附件 |
| `admin` | 授权校区的预约、容量、激活审核、纠错、转派、统计、导出及维修人员管理 |
| `superadmin` | 管理员权限及低级账号的管理员权限管理 |

所属校区不自动授权；账号管理仅限本人权限范围内的低级、非保护账号。`root001`、`root002` 为受保护最高权限账号，仅本人验证旧密码后改密。

部员须在白名单内，通过 `/staff/?activate=1` 申请并由管理员核验批准。白名单 CSV 每次最多 200 条，必含 `studentId`，可选 `expectedName`、`expectedRole`、`authorizedCampuses`（多校区用 `|`）；重复学号或格式错误整批拒绝，已有记录跳过。普通管理员仅审核维修人员。

私人链接通过 URL fragment 携带凭证，API 使用 `X-Appointment-Token`，凭证不放查询参数；编号、学号和二维码不能替代凭证。遗失凭证须由管理员核验身份后补发，旧凭证立即失效。工作人员 JWT 有效期 8 小时，退出、改密、停用或权限变化后撤销。

状态、地点和名额约每 30 秒刷新，页面隐藏时暂停；附件均经鉴权 API 访问，工作人员通用附件上限 5 MiB。持久化与兼容规则见 [数据模型](data-model.md)。
