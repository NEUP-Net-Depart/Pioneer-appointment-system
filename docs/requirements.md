# 业务规则与权限

先锋网络中心硬件部为南湖、浑南校区提供免费维修，配件和其他耗材由机主自备，清灰换硅脂提供普通硅脂。技术入口见 [README](../README.md)，部署和备份见 [运维文档](operations.md)。

## 预约规则

| 项目 | 当前规则 |
|---|---|
| 入口 | 访客免注册；浏览器自动保存预约凭证；凭私人链接跨设备访问 |
| 日期 | `Asia/Shanghai`，今天至第 3 天（含两端），仅周一至周四 |
| 时段与容量 | 19:00–21:00 分为四个半小时时段；管理员按授权校区、周一至周四和时段配置人数；已有预约日期保留排班，修改仅影响尚未预约的日期 |
| 暂停与下调 | 人数为 0 暂停新增预约；低于已有预约数时不撤销原预约，已有预约仍可查询、取消、签到和维修 |
| 重复预约 | 同一学生同日不能预约重叠时段，跨校区及新旧时段也受限 |
| 名额释放 | 仅 `completed` 且结果为 `cancelled` 的预约释放名额；已完成维修和未到场仍占当日名额，恢复已取消的预约需检查实时容量 |
| 访客取消 | 仅可取消自己的 `booked` 预约 |
| 预约编号 | 新预约使用 `reserve{校区代码}{预约日期YYYYMMDD}-{序号}`；南湖 `0`、浑南 `1`，按校区和预约日期递增，各时段共用序列，至少两位序号，取消或未到场不回收 |
| 全流程编号 | 预约、查询、排队、签到、维修、结束、附件和导出复用预约编号；停止生成独立维修编号，历史编号原样保留 |
| 协议签名 | 点击同意协议弹出手写板，完整签名确认后才能提交；支持鼠标、触屏、触控笔 |
| 签到照片 | 本次签到人必须上传电脑正、反两面图片，全部保存后才进入维修中；图片沿用附件大小和保留期限 |
| 附件 | JPG、PNG、WEBP、PDF、UTF-8 TXT，单文件最多 5 MB，自上传起保留 180 天 |

预约收集学号、姓名、校区、联系方式、设备和故障信息、日期时段及协议记录。QQ/微信必填；手机号、学院/专业、序列号、故障描述和备注等选填，完整字段见 [输入校验](../src/lib/validation.js)。用户页每 30 秒刷新名额或排队信息，隐藏标签页时暂停。

管理员在工作人员端“个人设置 → 预约人数设置”中按校区查看整周人数表，填写非负整数人数，支持框选、行列选择、拖动复制、跨校区及 Excel 复制粘贴、统一填写及一次保存全部修改。读取最新配置保留草稿，并发修改冲突时需放弃修改后重新读取。学生端按各时段显示剩余人数，最低为 0；暂停或满额时不可选择，已选时段失效时清空选择。

学生端顶部统一选择校区、日期和时段，只显示预约范围内未结束的服务时段，校区与表单同步，沿用原接口及提交字段。选择后立即反馈，已有名额先显示缓存再后台更新；提交时由服务端校验并原子检查容量。选择器滑出屏幕后显示时间摘要，未选择时提示“请先选择时间”，点击可返回；时段失效时提示重选并保留已填表单。

事件时间保存为 UTC ISO，业务日期按上海时区计算。

## 角色与权限

| 角色 | 权限 |
|---|---|
| `technician` 维修人员 | 仅查看授权校区的待接单摘要和本人订单；接单后才能读详情与附件，不可转派 |
| `admin` 管理者 | 管理授权校区内的预约、时段人数配置、审核、派单、调整状态、统计及导出；管理维修人员账号 |
| `superadmin` 最高权限者 | 继承管理者权限，可调整低级账号角色，包括授予或收回管理者权限 |

管理者和最高权限者只能编辑、启停或重置密码低于自身且非保护的账号；停用账号保留维修历史，不提供删除账号接口。除 `root001`、`root002` 外，工作人员账号为 6–20 位数字学号。两个 root 受保护，管理 API 不可修改；本人可以验证当前密码后在个人设置中改密。

## 状态与统计

新预约进入 `booked`（已预约），工作人员点击签到后上传正反面照片，确认后记录当前登录人员和服务端开始时间，进入 `in_progress`（维修中）。填写结果与维修说明后进入 `completed`（已结束），记录结束时间并继续使用原预约编号。结果包括 `repaired`（修复成功）、`unrepaired`（无法维修）、`not_needed`（无需维修）；取消和未到场也归入已结束，但结果为 `cancelled` / `no_show`。所有结束方式和管理员纠错均不生成维修编号。预约当天 21:30 后仍未签到的记录自动结束为未到场。

历史预约号和维修号原样保留，支持查询和导出；已有维修号标注为“历史维修编号”。学生查询仍需有效预约凭证。

维修人员按 [状态流转规则](../src/services/appointments.js) 操作；并发签到和更新通过 D1 revision 检查。管理员不能以纠错直接跳过首次签到拍照。统计支持指定日期或最近 7 天、30 天、全部记录，包含校区、故障和维修人员工作量；已结束中的维修结果与取消、未到场分别统计。

## 隐私与协议

- 密码使用 scrypt 哈希，联系方式使用 AES-256-GCM 加密。JWT 有效期 8 小时，工作人员会话存于 sessionStorage；退出、改密、停用、角色或授权校区调整会撤销旧会话。
- 服务端逐次校验账号、角色和对象权限。限流记录存于 D1，按 Cloudflare IP 的 HMAC 值计数，具体额度见 [限流服务](../src/services/rate-limits.js)。附件校验 MIME 和文件签名，仅通过鉴权 API 获取。
- 提交前同意免责协议并手写本人姓名（取消签名不会视为同意）：免费自愿、尽力维修但不保证修复、数据损失由机主承担、配件自备、在保优先官方售后。机主应先备份数据并遵守现场秩序；维修人员不得翻阅个人文件或聊天记录。协议正文见 [用户页面](../frontend/user/index.html)。

权限检查集中在 src/services/permissions.js。所属校区不推导权限；调整授权校区撤销所有旧会话。维修人员对未接单摘要的姓名、学号搜索也受限制，不能通过筛选推断未授权隐私。个人设置支持本人改密和撤销所有会话。
