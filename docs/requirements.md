# 业务规则与权限

先锋网络中心硬件部为南湖、浑南校区提供免费维修，配件和耗材由机主自备。技术入口见 [README](../README.md)，部署和备份见 [运维文档](operations.md)。

## 预约规则

| 项目 | 当前规则 |
|---|---|
| 入口 | 访客免注册；浏览器自动保存预约凭证；凭私人链接跨设备访问 |
| 日期 | `Asia/Shanghai`，今天至第 3 天（含两端），仅周一至周四 |
| 时段与容量 | 19:00–20:00、20:00–21:00；每校区每时段 20 人 |
| 重复预约 | 同一学生同日同时段只能有一个占名额预约，跨校区也受限 |
| 名额释放 | 仅 `cancelled`、`no_show` 不占名额；恢复预约也需检查容量 |
| 访客取消 | 仅可取消自己的 `pending`、`awaiting_claim` 预约 |
| 编号 | `{校区代码}{YYYYMMDD}-{序号}`，南湖 `0`、浑南 `1` |
| 附件 | JPG、PNG、WEBP、PDF、UTF-8 TXT，单文件最多 5 MB，自上传起保留 180 天 |

预约收集学号、姓名、校区、联系方式、设备和故障信息、日期时段及协议记录。QQ/微信必填；手机号、学院/专业、序列号、故障描述和备注等选填，完整字段见 [输入校验](../src/lib/validation.js)。用户页每 30 秒刷新名额或排队信息，隐藏标签页时暂停。

容量调整须同步修改 [shared/constants.js](../shared/constants.js) 并新增 SQL 触发器迁移。事件时间保存为 UTC ISO，业务日期按上海时区计算。

## 角色与权限

| 角色 | 权限 |
|---|---|
| `technician` 维修人员 | 查看预约、筛选列表，接待审核或待接单订单；仅处理自己的订单和维修记录，不可转派 |
| `admin` 管理者 | 管理全部预约、审核、派单、调整状态、统计及导出；管理维修人员账号 |
| `superadmin` 最高权限者 | 继承管理者权限，可调整低级账号角色，包括授予或收回管理者权限 |

管理者和最高权限者只能编辑、启停或重置密码低于自身且非保护的账号；停用账号保留维修历史，不提供删除账号接口。除 `root001`、`root002` 外，工作人员账号为 6–20 位数字学号。两个 root 受保护，管理 API 不可修改。

## 状态与统计

新预约进入 `pending`（待审核），可转为 `awaiting_claim`（待接单），维修人员也可直接接待审核订单。接单后为 `claimed`（已接单），可进入 `in_progress`（维修中），最终为 `completed`（已完成）、`no_repair`（无法维修）或 `no_show`（爽约）；取消状态为 `cancelled`。

维修人员按 [状态流转规则](../src/services/appointments.js) 操作；并发抢单和更新通过 D1 revision 检查。统计支持指定日期或最近 7 天、30 天、全部记录，包含校区、故障和维修人员工作量；故障分类仅统计 `completed`。

## 隐私与协议

- 密码使用 scrypt 哈希，联系方式使用 AES-256-GCM 加密。JWT 有效期 8 小时，工作人员会话存于 sessionStorage；退出、改密、停用、角色或授权校区调整会撤销旧会话。
- 服务端逐次校验账号、角色和对象权限。限流记录存于 D1，按 Cloudflare IP 的 HMAC 值计数，具体额度见 [限流服务](../src/services/rate-limits.js)。附件校验 MIME 和文件签名，仅通过鉴权 API 获取。
- 提交前同意免责协议：免费自愿、尽力维修但不保证修复、数据损失由机主承担、配件自备、在保优先官方售后。机主应先备份数据并遵守现场秩序；维修人员不得翻阅个人文件或聊天记录。协议正文见 [用户页面](../frontend/user/index.html)。
